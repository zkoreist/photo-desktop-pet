# Photo Desktop Pet

将你有权使用的照片变成私人、本地的 Windows 桌面伙伴。目标平台为 Windows；不上传照片、不进行人脸识别或身份推断。

## 当前状态

已完成：

- React 原型与可测试的桌宠移动引擎（垂直移动 + 概率状态机 + seeded 随机）
- Tauri 2 透明、无边框、始终置顶的原生宠物窗口与系统托盘菜单
- 图片导入：托盘「导入图片…」→ 校验格式/大小 → 复制到应用数据目录 → 生成 ID → 「删除当前图片」
- 位置持久化：桌宠在显示器工作区内走动并重启恢复位置（运行时动态探测 DPI，兼容任意缩放比例）
- 引擎单元测试（Vitest，13 项）

已知限制：拖拽移动暂不可用（待修）；JPG/WebP 仅用于预览；自动去背景非 v0.1 功能。

## 运行

```bash
npm install
npm run dev        # Web 交互原型
npm run tauri:dev  # Windows 原生桌宠（开发模式）
```

推荐导入已去背景的 PNG。

## 打包安装（Windows）

```bash
npm run tauri:build
```

产物为 `.exe` 安装包（NSIS），位于 `src-tauri/target/release/bundle/nsis/`。安装界面可选简体中文/英文，免管理员权限安装到当前用户。

## SmartScreen 说明

当前发布的安装包**未做代码签名**（尚未配置代码签名证书）。Windows SmartScreen 可能在首次运行时提示「未知发布者」。这是正常的未签名应用警告，并非安全威胁：

- 点击「更多信息」→「仍要运行」即可继续；
- 不放心可从源码自行构建（见「运行」）；
- 获得代码签名证书后会签名发布，届时该警告消失。

请勿为绕过该警告而关闭 SmartScreen 或修改系统安全设置。

## 隐私与授权

图片仅应由拥有者或得到授权的用户导入。请勿把真人图片、密钥或私人应用数据提交到仓库。详见 [docs/privacy.md](docs/privacy.md)。
